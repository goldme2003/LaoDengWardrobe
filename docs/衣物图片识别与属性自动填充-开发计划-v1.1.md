## 1. 目标与范围

在衣物录入（拍照/相册选图）流程中自动识别照片内容，预填衣物属性，用户确认或修正后保存，将录入成本从「手动选 5+ 个属性」降为「确认/微调 1–2 个属性」。

**本方案覆盖的识别场景（重点扩展）**：

| 场景 | 输入内容 | 产出 |
| --- | --- | --- |
| S1 衣物主体识别 | 衣物整体照片 | 含衣判定、服装类型（品类）、颜色、内外穿默认值、季节建议 |
| S2 吊牌/标签识别 | 衣物吊牌、水洗唛、成分标签区域照片 | **面料成分、清洗说明（洗涤图标/文字）、尺码、品牌等文字类属性**（经 OCR） |
| S3 非衣物图片 | 风景/食物等 | 不填充任何属性，明确提示重新拍摄 |

**明确不在本期范围**：品牌 Logo 精确识别（仅 OCR 提取吊牌上的品牌文字）、洗护提醒、图像抠图/背景处理、视频识别。

## 2. 总体技术方案

### 2.1 架构原则

- **识别能力全部走服务端中转**：小程序前端不放置任何云服务密钥（API Key 不可打包进前端）；所有识别请求经**微信云开发云函数**中转调用第三方识别 API。
- **与云端化节奏对齐**：当前 MVP 为纯本地存储（PRD 6.3），本功能是首个引入后端能力的特性，采用微信云开发（与既有 `cloudfunctionRoot: cloudfunctions/` 配置一致），为 6.3 云端同步做架构铺垫。
- **识别永不阻塞手动录入**：识别失败/超时（≤5s）静默跳过，用户仍走完整手动流程。

### 2.2 技术选型

| 能力 | 选型 | 备选方案 | 选型理由 |
| --- | --- | --- | --- |
| 含衣判定 + 品类识别 + 颜色提取 | **腾讯混元视觉大模型**（v1.1 评审确认，云函数调用，Prompt 输出结构化 JSON） | 通义千问 VL；腾讯云图像标签 + 自研映射规则 | 单次调用同时输出品类/颜色/季节建议与吊牌文字理解，免去多模型拼装；与微信生态一致；映射到 6.1 预设类型由云函数完成 |
| 吊牌/标签文字 OCR（面料成分、清洗说明、尺码、品牌） | **腾讯云通用印刷体 OCR**（v1.1 评审确认，云函数调用，按量计费，每月 1,000 次免费额度） | 微信服务市场 OCR；多模态大模型直接读图提取文字 | 专用 OCR 对印刷体小字识别率更高、单价更低；大模型做语义理解（如将「60%棉 40%涤纶」「可机洗 温水」映射为属性字段），OCR 做精确文字兜底 |
| 触发与编排 | 云函数 `recognizeClothing`：照片临时链接 → 大模型识别 →（可选）OCR 二次确认 → 属性映射与置信度过滤 → 返回结构化结果 | 前端直连（否决，密钥不安全） | 统一编排「先判衣物主体、再读吊牌」两步流程，统一降级逻辑 |
| 季节建议 | 端侧规则：类型 + 当前月份 → 季节多选（如羽绒服→秋/冬） | 大模型直接输出 | 规则简单、零成本、可控可测 |

### 2.3 识别流程

```text
【选图后自动触发】（v1.1 评审确认 Q4 = A 自动触发）
用户在 add 页/试穿编辑页获得照片组
  → 新照片加入约 800ms 防抖后自动识别（默认识别第 1 张主图；组内可手动切换识别任一张）
  → 同一张照片的识别结果本地缓存（按照片临时路径哈希），不重复调用
  → 上传压缩图（≤1MB，长边 ≤1280px）→ 云函数 recognizeClothing
  → ① 含衣判定：混元视觉模型判断图中是否为衣物
       否 → 返回 no_clothing，前端提示「未识别到衣物，请重新拍摄」
  → ② 品类/颜色识别：模型输出类型/颜色/内外穿建议 + 置信度（映射至 6.1 预设）
       置信度 < 0.6 的字段 → 置空不预填，仅 toast 提示「建议手动确认」
  → ③ 吊牌检测：模型判断图中是否含吊牌/水洗唛区域
       是 → 裁剪该区域送腾讯云 OCR → 提取面料成分/清洗说明/尺码/品牌文字
       → 云函数规则解析（成分正则：棉/涤纶/羊毛/%比例；清洗关键词：机洗/手洗/不可漂白…）
  → ④ 返回结构化 JSON：{ category, colors[], layer(内外穿), seasons[], material,
        size, brand, careText, compositionText, confidence{}, warnings[] }
  → 前端预填属性表单（已填字段不覆盖；用户改动后不再覆盖），材质/备注（清洗说明）填入对应控件
  → 用户确认/修正 → 正常保存（走既有本地存储链路）
  ※ 自动识别失败/超时不自动重试（避免浪费调用），按钮旁提供「重新识别」手动入口
  ※ 用户可全局关闭自动识别（开关持久化），关闭后仅保留手动「重新识别」入口
```

### 2.4 交互原则（与 PRD 9.3 一致并细化）

1. 所有自动填充值均可修改；用户改动后系统不再覆盖。
2. 选图后自动触发识别（v1.1 评审确认），过程展示加载态（按钮 loading + 骨架提示），超时 5s 自动终止并静默跳过；失败不自动重试，提供手动「重新识别」入口。
3. 识别失败/超时不弹错误弹窗打断录入，仅按钮旁轻提示「识别不可用，请手动填写」。
4. 照片含吊牌时，拍摄引导文案：「建议补拍一张吊牌/水洗唛照片，可自动识别面料与清洗说明」。
5. 隐私合规：首次自动触发识别前提示「照片将上传用于识别，不上传至公开网络」；拒绝后本次及后续均不自动触发（开关持久化），仅保留手动入口，纯手动录入不受影响。
6. **熔断机制（v1.1 评审确认 Q5，月预算上限 50 元）**：
   - 前端按本地记录的当月识别成功次数 × 单价估算值（大模型 0.05 元/次 + OCR 0.01 元/次保守取值）累计估算月成本；
   - 月估算成本达到 40 元（80%）时，自动识别改为仅手动触发并提示「本月识别额度即将用尽」；
   - 达到 50 元上限时熔断：停止一切识别调用（云函数侧同步校验拒绝），提示「本月识别额度已用尽，下月自动恢复」，手动录入不受影响；
   - 计数按自然月重置，云函数侧以数据库计数为准防止前端绕过。

## 4. 成本与配额评估

| 项 | 说明 |
| --- | --- |
| 多模态大模型 | 按次计费（单图约 0.01–0.05 元/次，视供应商）；个人使用量级（百件衣物）总成本预计 < 20 元 |
| 腾讯云 OCR | 通用印刷体识别每月免费额度 1,000 次，超出约 0.01 元/次；吊牌识别仅在检测到吊牌时调用，调用量约为品类识别的 1/3 |
| 云开发 | 云函数 + 临时存储，个人版基础配额预计足够 |
| 控制策略 | 前端对同一张照片识别结果本地缓存，避免重复调用；自动触发 800ms 防抖；**月熔断预算 50 元（v1.1 评审确认）**：40 元预警转仅手动、50 元硬熔断，云函数侧数据库计数为准，自然月重置 |

## 5. 风险点评估

| # | 风险 | 等级 | 缓解措施 |
| --- | --- | --- | --- |
| R1 | 品类/颜色识别准确率不达 PRD 验收线（≥85%） | 中 | Prompt 迭代 + 少样本示例；置信度阈值过滤（<0.6 不预填）；识别错不阻塞，用户可改 |
| R2 | 吊牌折叠/反光/手写字导致 OCR 失败或乱码 | 高 | OCR 失败静默跳过文字属性；引导用户「拍平整的吊牌正面」；成分解析采用宽松正则 + 关键词表，解析不出原文入备注 |
| R3 | 云服务密钥泄露（若误打包进前端） | 高 | 强约束：密钥仅存云开发环境变量；代码评审检查项；前端只调云函数 |
| R4 | 照片上传隐私合规 | 中 | 上传前隐私提示 + 一次性授权开关；仅上传压缩缩略图用于识别，原图仍存本地 |
| R5 | 识别耗时超 5s 体验差 | 中 | 图片压缩至 ≤1MB；云函数并发调用大模型与 OCR；超时中断 + 静默降级 |
| R6 | 大模型服务可用性/供应商变更 | 中 | 接口层抽象 Provider，可切换混元/千问等；失败降级为手动录入（产品可用性不受影响） |
| R7 | MVP 引入云开发与「本地存储」设定冲突 | 低 | 云函数仅承载识别中转，不存储衣物数据；PRD 6.3 存储规则不变，需在 PRD 中补一句「识别类网络请求除外」 |

## 6. 验收标准

**通用（承 PRD 9.3）**：

- 含衣判定误报率 ≤ 5%（非衣物图片不填充、有明确提示）；
- 常见品类（上装/裤装/裙装/鞋履/配饰）识别准确率 ≥ 85%；
- 识别成功后服装类型、内外穿、颜色自动预填且可立即修改，修改结果正确保存；
- 识别有加载态，失败/超时（≤5s）不影响手动录入，无崩溃卡死。

**OCR 专项（本方案新增）**：

- 吊牌/水洗唛照片中，面料成分抽取准确率 ≥ 80%（测试集 ≥ 50 张清晰吊牌）；
- 清洗说明关键词（机洗/手洗/水温/不可漂白/不可熨烫等 ≥ 10 类）抽取准确率 ≥ 80%，抽取失败时原文写入备注不丢失；
- OCR 结果能正确填入材质/尺码/品牌/备注对应控件，与人工选择不冲突（已填字段不覆盖）；
- OCR 单次调用耗时 ≤ 3s（不含大模型阶段），月调用量在免费额度内可完成典型使用。

**安全与合规**：

- 前端代码与小程序包内检索不到任何云服务密钥；
- 隐私提示与拒绝后降级路径可用。
