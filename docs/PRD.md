## 1. 背景与目标

个人衣物的照片、颜色、材质、季节属性分散在记忆和照片相册中，用户在穿搭决策（如「今天下雨，找一件深色的春季外套」）时无法快速定位自己的衣物，也难以在不翻衣柜的情况下了解自己拥有什么。

老登衣柜是一个面向个人的衣物管理微信小程序：用户通过拍照快速记录衣物，并为衣物标注颜色、材质、季节属性；之后可以按这些维度浏览和筛选自己的衣柜。

**可观察的产品结果**：用户在 1 分钟内可以完成一件衣物的拍照录入；录入后，用户可以按颜色、材质、季节任一维度筛选并看到对应衣物列表，点开任一衣物可查看其照片与属性。

## 2. 范围

### 2.1 MVP 范围（P0）

最小完整旅程：**打开小程序 → 拍照/选图 → 补充属性 → 保存 → 按维度筛选查看 → 查看详情 → 删除**。

| 编号 | 能力 | 说明 |
| --- | --- | --- |
| FR-01 | 拍照/选图录入衣物 | 相机拍摄或从相册选择 1 张照片作为衣物主图 |
| FR-02 | 衣物属性编辑 | 录入与编辑时设置名称、颜色、材质、季节 |
| FR-03 | 衣柜列表与分类筛选 | 衣物总列表 + 按颜色 / 材质 / 季节筛选 |
| FR-04 | 衣物详情查看 | 查看大图与全部属性 |
| FR-05 | 衣物删除 | 从列表或详情删除衣物，删除前确认 |

### 2.2 P1（本版不做，架构上不排斥）

- 多图 / 细节图；
- 品类维度（上装、下装、外套、鞋、配饰等）；
- 穿着/搭配记录；
- 云端同步与微信登录（见 5.4 存储规则：MVP 为本地存储，数据结构与存储层设计需保证未来可替换为云端存储，但本版不实现登录与同步界面）。

### 2.3 排除项

- 社交、分享、电商、比价、二手交易；
- 洗护/保养提醒；
- 多用户/家庭共享衣柜；
- AI 自动识别颜色、材质、品类（MVP 阶段属性由用户手动选择）。

## 3. 产品模型

### 3.1 核心对象：衣物条目（Item）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 照片 | 图片，1 张 | 是 | 衣物主图，来源于拍摄或相册 |
| 名称 | 文本 | 否 | 最长 20 字；为空时列表与详情显示默认名（见 5.2） |
| 颜色 | 单选 | 否 | 取值来自颜色维度选项（5.1），支持自定义新增 |
| 材质 | 单选 | 否 | 取值来自材质维度选项（5.1），支持自定义新增 |
| 季节 | 多选（0–4 项） | 否 | 春 / 夏 / 秋 / 冬 |

- 除照片外全部属性可留空；留空的衣物仍出现在「全部」列表中，且在任何维度筛选下归属「未分类」分组（见 FR-03）。
- 录入时间由系统记录，用户不可编辑；列表按录入时间倒序展示。

### 3.2 状态

衣物条目仅两种状态：**正常** / **已删除**。已删除条目不出现于任何列表与筛选结果。MVP 无回收站，删除即最终生效（删除确认见 FR-05）。

## 4. 核心流程

```text
【录入】点击"添加衣物" → 选择 拍照 或 从相册选择 → 获得照片
        → 进入属性编辑（名称/颜色/材质/季节，均可跳过）→ 保存 → 返回列表，新衣物置顶

【查看】浏览列表（全部 或 按颜色/材质/季节筛选）→ 点击衣物 → 查看详情大图与属性

【删除】列表或详情中点击"删除" → 弹窗确认 → 条目移除，列表即时更新
```

## 5. 功能需求

### FR-01 拍照/选图录入衣物

**目的**：让用户用最少的步骤把一件衣物记录进衣柜。

**触发**：用户在衣柜页点击「添加衣物」。

**处理规则**：

1. 弹出选择：**拍照** 或 **从相册选择**。
2. 拍照：调起微信相机拍摄 1 张照片；取消拍摄则返回衣柜页，不产生条目。
3. 相册选择：调起微信相册选择器，限选 1 张图片；取消选择则返回，不产生条目。
4. 照片获取成功后，直接进入属性编辑页（FR-02），照片显示在编辑页顶部。
5. 照片以小程序可展示的格式与适中分辨率保存（具体压缩策略为技术实现，不在本文档定义）。

**例外**：

| 场景 | 行为 |
| --- | --- |
| 用户拒绝相机/相册权限授权 | 展示引导文案，提示去设置页开启授权；提供「从相册选择」或「拍照」的另一种入口重试 |
| 拍摄或选择中途取消 | 返回衣柜页，不产生条目，无报错提示 |

### FR-02 衣物属性编辑

**目的**：为衣物补充颜色、材质、季节等管理属性。

**触发**：FR-01 照片获取成功后（新录入）；或在衣物详情页点击「编辑」。

**处理规则**：

1. 编辑页顶部显示照片；提供「重拍/换图」入口，可重新走 FR-01 流程替换照片。
2. 名称：文本框，最长 20 字，可留空。
3. 颜色：单选，选项为预设项 + 用户自定义项（见 5.1 自定义规则）。
4. 材质：单选，选项为预设项 + 用户自定义项。
5. 季节：多选，勾选春 / 夏 / 秋 / 冬的任意组合（0–4 项）。
6. 「保存」按钮始终可点：保存后返回列表，新条目出现在「全部」列表顶部（按录入时间倒序）。属性可全部留空。
7. 编辑已有衣物时，保存覆盖原属性；照片未更换则保持不变。

**例外**：名称超长时输入框限制在 20 字，不做报错弹窗。

### FR-03 衣柜列表与分类筛选

**目的**：让用户按颜色、材质、季节快速找到衣物。

**触发**：进入小程序首页（衣柜页）。

**处理规则**：

1. **列表**：默认展示「全部」衣物，按录入时间倒序，以「照片缩略图 + 名称（或默认名）+ 已选属性标签」形式呈现。
2. **筛选**：提供三个筛选维度：颜色 / 材质 / 季节。
   - 颜色、材质：单选筛选（含「全部」和「未分类」选项）。
   - 季节：可勾选多个季节（春/夏/秋/冬），结果为所选季节的并集；含「全部」和「未分类」选项。
   - 三个维度可叠加，结果取交集；任一维度选「全部」表示该维度不限制。
   - 「未分类」= 该字段为空的衣物。
3. **空结果**：筛选无结果时展示空态文案与「添加衣物」入口。
4. **空衣柜**：没有任何衣物时，展示引导页与「添加衣物」主按钮。
5. 每个维度下的选项列表 = 预设项 + 用户自定义项（见 5.1）；自定义项一经使用，即可在该维度筛选中出现。

**例外**：自定义选项较多时，维度选项面板支持纵向滚动，不设数量上限。

### FR-04 衣物详情查看

**目的**：查看单件衣物的完整信息。

**触发**：在列表中点击任一衣物条目。

**处理规则**：

1. 展示照片大图与全部属性：名称（或默认名）、颜色、材质、季节、录入时间。
2. 属性为空的字段显示「未设置」，不隐藏字段。
3. 提供「编辑」（进入 FR-02）与「删除」（进入 FR-05）入口。

### FR-05 衣物删除

**目的**：移除不再拥有的衣物。

**触发**：在详情页点击「删除」；或列表条目上的删除操作。

**处理规则**：

1. 点击删除后弹窗确认：「删除后不可恢复，确定删除该衣物吗？」，提供「取消」与「删除」。
2. 确认删除后条目立即从所有列表与筛选结果中移除，并从本地存储中清除照片与属性数据。
3. 取消则无任何变更。
4. MVP 不设回收站与撤销（见 3.2）。

## 6. 共享规则与例外

### 6.1 分类维度与自定义规则

**预设选项（MVP 初版，可在后续版本调整）：**

| 维度 | 预设选项 | 选择方式 |
| --- | --- | --- |
| 颜色 | 黑色、白色、灰色、红色、橙色、黄色、绿色、蓝色、紫色、粉色、棕色、米色、牛仔蓝 | 单选 |
| 材质 | 棉、麻、丝绸、羊毛、羊绒、涤纶、牛仔、皮革、羽绒、醋酸、其他 | 单选 |
| 季节 | 春、夏、秋、冬 | 多选 |

**自定义规则（颜色与材质维度适用）：**

1. 在任一维度的选项面板底部提供「+ 自定义」入口。
2. 点击后弹出文本输入（颜色最长 6 字，材质最长 10 字），确认后该选项立即加入该维度的选项列表，并在当前衣物的编辑中默认选中。
3. 自定义选项与预设选项在编辑、筛选、展示上完全同权。
4. 自定义选项一旦被任一衣物使用，即不可删除；未被任何衣物使用的自定义选项可在选项管理中删除（选项管理入口位于筛选面板，MVP 仅提供删除未被使用的自定义项）。
5. 季节维度为固定枚举，不支持自定义。

### 6.2 默认名规则

衣物名称为空时，展示为「衣物 + 3 位序号」（如「衣物 007」）。序号为该条目在本衣柜中的录入顺序号，创建后固定不变，不随删除重排。

### 6.3 存储规则（先本地后云端）

1. MVP 阶段所有数据（照片与属性）保存在用户设备本地，无需登录即可使用。
2. 数据结构与存储访问层的设计需保证：后续版本引入微信登录与云端存储时，可在不改变用户可见行为的前提下替换存储实现；本版不实现任何登录、同步界面或网络请求。
3. 卸载小程序或清除小程序数据会导致本地数据丢失；MVP 在设置入口（P1，暂以「关于」页代替）展示一次性数据提示文案，但不提供导出功能。

### 6.4 权限

MVP 为单用户个人工具，无角色区分；仅使用微信小程序运行时要求的设备权限（相机、相册）。
